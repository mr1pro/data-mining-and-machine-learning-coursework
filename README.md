# Data Mining and Machine Learning Coursework

University team project repository.

## Getting Started
1. Clone the repo: `git clone https://github.com/mr1pro/data-mining-and-machine-learning-coursework.git`
2. Create a branch for your work: `git checkout -b your-name/feature`
3. Push your branch and open a Pull Request for review before merging to `main`

## Structure
- `/data` — datasets (raw and processed)
- `/notebooks` — exploratory analysis, Jupyter notebooks
- `/src` — reusable code/modules
- `/reports` — write-ups, figures, final report
